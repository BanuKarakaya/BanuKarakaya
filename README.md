## 🚀 Featured Projects

### [PipePulse](https://github.com/BanuKarakaya/PipePulse)
A native macOS menu bar app for monitoring CI/CD pipelines. It includes provider-independent pipeline models, mock integrations, Keychain-backed credential storage, and a Swift Package Manager setup.

**Swift · macOS · SwiftUI · CI/CD · Keychain**

### [Nudge](https://github.com/BanuKarakaya/Nudge)
A Go backend project with PostgreSQL, scheduled jobs, secure integrations, and adapters for AI, Feedbin, Raindrop, and Slack.

**Go · PostgreSQL · Docker · REST APIs · Integrations**

### [BanuBlog](https://github.com/BanuKarakaya/BanuBlog)
My personal blog built with Next.js, React, TypeScript, Tailwind CSS, and Sanity.  
🌐 [Visit the live blog](https://banu-blog-drab.vercel.app)

**Next.js · React · TypeScript · Tailwind CSS · Sanity**

### [NutraPair](https://github.com/BanuKarakaya/NutraPair)
A social nutrition and fitness app that combines AI-powered meal recognition, calorie tracking, activity monitoring, Apple Health integration, and social accountability.

**Swift · UIKit · HealthKit · REST APIs**

### [WaterBoost](https://github.com/BanuKarakaya/WaterBoost)
A SwiftUI hydration app that connects water consumption with app access through Screen Time APIs. It uses CoreMotion animations, App Groups, and extension-based monitoring to create a reward-based habit system.

**Swift · SwiftUI · CoreMotion · FamilyControls · ManagedSettings · DeviceActivity**
